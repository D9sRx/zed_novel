# 00. 项目愿景

## 目标

做一个真正可在 Zed 中使用的本地小说阅读扩展：保持编辑器原生体验，章节导航快速，恢复进度可靠，并提供低调的代码注释伪装。

## 用户故事

- 导入 UTF-8、GBK/GB18030 TXT，中文不乱码。
- 导入无 DRM EPUB，保留 spine 章节顺序和基本段落。
- 在 Zed Outline 中搜索并跳转章节。
- 关闭和重开工作区后恢复大致阅读位置。
- 显式保存可靠书签，避免会话恢复失效。
- 选择普通或注释伪装输出。

## MVP 非目标

- 在线书城、盗版书源、账号同步、云书架。
- 破解 EPUB DRM。
- 完整还原 EPUB CSS、复杂排版、图片和脚注弹窗。
- 自定义侧边栏/WebView（当前 Zed 扩展 API 不支持）。
- 自动隐藏窗口或模拟办公行为。
- 自动监听每次滚动并精确保存百分比（API 不足）。

## 成功标准

- 10 MB TXT 可成功导入，常见中文编码不乱码。
- “第 N 章/卷/回”等标题可在 Outline 识别。
- 无 DRM EPUB 按 spine 顺序生成可读正文。
- 显式书签重启后仍能恢复。
- Dev Extension 在本机 Zed 完成端到端验收。

## 隐私与安全

默认完全离线；不上传正文、路径或进度。只写用户指定目录。EPUB 解压阻止 Zip Slip；HTML 不执行脚本、不拉取远程资源。
