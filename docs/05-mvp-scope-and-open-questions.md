# 05. MVP 范围与待确认项

## 建议默认值

| 决策 | 建议 |
|---|---|
| 项目名 | Zed Novel Reader |
| 扩展 ID | `novel-reader` |
| 默认风格 | `/** ... */` JSDoc 块注释伪装（已确认） |
| 输入 | 本地 TXT、无 DRM EPUB |
| 输出 | `.novel` + 可选 `.novel-state.json` |
| 在线功能 | 全部关闭 |
| 进度 | Zed 会话恢复 + 显式书签（已确认） |
| 初始交付 | Dev Extension + Windows 可运行 CLI |
| 许可证 | MIT（已确认，按公开发布准备） |

## 已确认的 MVP 决策

1. EPUB 先导入为 `.novel`，而不是直接打开 `.epub` 标签页。
2. 进度采用“Zed 自动恢复大致位置 + 显式书签可靠恢复”，不宣称每次滚动自动保存。
3. 默认伪装采用 `/** ... */` JSDoc 块注释，正文行使用 ` * ` 前缀。

## 编码前确认状态

全部 MVP 决策已确认，可以进入 Phase 1。

## 已确定边界

不做在线盗版书源；不破解 DRM；不 fork Zed；只用官方扩展能力；确认本文档前不进入业务编码。

## 后置选项

更多伪装模板、书架索引、全文搜索、多设备同步、图片提取、发布到 registry/npm。
